# 次にやることの候補（未実装）

縄張りと旅立ちで「血縁者が近くに固まって住む」ようになったので、それを土台にした案を中心に並べる。
どれも手で決めた有利・不利の表は使わず、行動 1〜2 個から結果が生まれる形にする。

## おすすめ順

### 1. （済）警戒声（血縁選択・ハミルトンの規則）
- 捕食者に気づいた個体が鳴くかどうかを遺伝子で決める。鳴くと近くの個体の被食率が下がり、鳴いた本人の被食率は少し上がる。
- 「家族を守るために損をする」遺伝子は、近くにいるのが血縁者のときだけ広まる。縄張りで家ごとに固まるようになった今なら、規則として書かなくても起きるはず。旅立ちの距離が長い島では広まりにくい、という比較もできる。
- 見どころ：家ごとの「鳴き屋の割合」、捕食者が多い時代に鳴き声が増えるか。

### 2. 鳴き声の方言（文化の伝達 → 行動による種分化）
- オスの歌は遺伝ではなく、父（または近所のオス）から学ぶ。まねるときに少しずつずれる。メスは子どものころに聞いた歌に似た歌を好む（刷り込み）。
- 縄張りがあるので、集落ごとに方言ができる。陸橋で島がつながっても方言が違うと交わりにくい → 遺伝子の壁（不和合）と文化の壁がどう絡むかを見られる。
- 見どころ：地図の表示「方言」、方言の系統樹。遺伝子ではない「もうひとつの遺伝」。

### 3. 強化（雑種が損なら、似た相手を選ぶ好みが進化する）
- 「自分と同じ模様の相手を好む」遺伝子を足す。いまは雑種の不和合があるので、東と西が出会う場所（陸橋・流木）では、似た相手を好むメスほど子を多く残す。
- 交雑帯で好みが強まり、壁が崩れにくくなる（本物の種分化の最後の一押し）。種分化の続きとして自然。

### 4. 利己的な X 染色体（減数分裂駆動）
- X 上に「Y を持つ精子を壊す」遺伝子を置く。持つオスの子はほとんど娘になる。遺伝子自身は広まるが、オスが減りすぎると集団が危うくなる。
- 常染色体に抑制遺伝子が現れると性比が戻る。性比がぐらぐら揺れる「ゲノムの中の争い」が見られる。

### 5. もしもの歴史（保存を使った分岐）
- 保存が「同じ歴史を完全に再現できる」ので、ある年から枝分かれさせて「ここで大嵐がなかったら」を並べて比べられる。
- 2 つの世界を並べて、体色や家の勢力の推移を重ねて表示する。遺伝的浮動（偶然）と選択（必然）の区別が体感できる。

### 6. 病原体との共進化（赤の女王）
- 今の免疫型（超優性）は有利さを決めているが、病原体の側も型を持って、多い免疫型に合わせて変わるようにする。多数派の免疫型ほど病気にかかる（負の頻度依存）ので、手決めの超優性なしで多型が保たれる。
- 有性生殖の意味（なぜ遺伝子を混ぜるのか）に直結する題材。
