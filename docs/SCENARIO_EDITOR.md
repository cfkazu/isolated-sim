# シナリオを画面で作る：設計

## 1. 目的と原則

- コードを書かずに、画面だけで「島の始まり方」を作り、保存し、遊び、人に渡せるようにする。
- シナリオが決めるのは**始まり方だけ**。始まったあとの規則（遺伝・選択・生態）は変えない。どんなに恣意的な始まり方でも、その後に起きることは本物。
- 今ある組み込みシナリオ（src/scenarios.js）と**同じデータ形式**を使う。組み込みシナリオを複製して手直しするところから始められる。
- 画面をごちゃごちゃさせない：ふだんは何も増えず、作るときだけ編集画面が開く。遺伝子の指定は、指定したいものだけ行を足す方式にする。

## 2. 画面の流れ

設定タブの「シナリオ」の横に「✏️ 作る・直す」ボタンを置く。押すと、右側のパネルがシナリオ編集画面に切り替わり、左の地図は「下書きの島のプレビュー」になる（地形編集と同じく、地図を使うモード）。シミュレーションは一時停止する。

編集画面は上から順に 5 つの区画。上から埋めれば完成する。

```
┌ シナリオ編集 ────────────────────────────┐
│ ① 土台   [四つの村 ▼] を複製 / 空から / 今の島から │
│ ② 島     形・地質・シード・豊かさ・捕食者・気候の始まり │
│ ③ 群れ   ● 北西の村 25% 同じ家 東   [遺伝子 +]  │
│          ● 北東の村 25% …                 │
│          [＋ 群れを足す]                        │
│ ④ 全員の遺伝子   体色 [K ▮▮▯ G ▮▮▮ w ▯]  [＋] │
│ ⑤ 予定の出来事   30 年目 超寒冷期  [＋]         │
│ ⑥ 名前・説明・見どころ                          │
│ [保存] [保存して始める] [書き出す] [やめる]      │
└──────────────────────────────────────────┘
```

### ① 土台
- 「組み込み・自作のシナリオを複製」「空から（自由と同じ）」「今の島から」の 3 つ。
- 「今の島から」は、いま遊んでいる島の地質・形・シードと、**今の遺伝子の割合**を全員の遺伝子（④）に写す。「この島の遺伝子のまま、別の地形・別の始まり方で試す」ができる。個体の位置や家までは写さない（写すなら保存の機能を使う）。

### ② 島
- 今の設定タブと同じ項目（島の形・地質・シード・最初の個体数・島の豊かさ・最初の捕食者の数）に、「気候の始まり」（間氷期／寒冷化の途中／氷期の底／温暖化）を足す。
- 変えるとすぐ左の地図のプレビューが描き直される（島だけ生成するので軽い）。

### ③ 群れ（いちばん大事な区画）
- 群れごとに：名前・割合（％）・置き場所・同じ家にするか・出身（東／西／まぜる）・この群れだけの遺伝子。
- **置き場所は地図で決める**：群れの行を選んで地図をクリックすると中心が決まり、ドラッグで半径を変える。地図には群れごとに色の付いた円と名前を描く。海の上に置いたら円を赤くし、「近くの陸地に置かれます」と出す。
- 群れがなければ、今までどおり島じゅうに散らす。
- 割合の合計が 100% でなくてもよい（比で分ける）。下に「最初の 100 匹 → 北西 25 匹・北東 25 匹…」と実際の数を出す。

### ④ 全員の遺伝子 と、群れごとの遺伝子
- 41 の遺伝子座を全部並べると使えないので、**形質の単位**で指定する。指定したい形質だけ「＋」で行を足す。書かなかったものはいつもの割合。
  - 1 つの遺伝子座で決まるもの（体色・模様・発光・免疫型・換毛・色素・警戒声・致死因子など）：対立遺伝子ごとの割合を帯グラフのつまみで決める。
  - 量的形質（体格・毛皮・代謝・尾・好み・旅立ち）：「＋」の割合を 1 本のつまみで決め、その形質の全遺伝子座に同じ値を入れる。
  - 不和合（種分化）の遺伝子は、群れの「出身」で決める。
- 群れの遺伝子は全員の遺伝子に上書きする（群れで指定したものだけ）。
- 「詳しく」を開くと遺伝子座ごとに指定できる（上級者向け、ふだんは閉じておく）。

### ⑤ 予定の出来事
- 「◯ 年目に △」の行を足す。△ は神の介入と同じ 8 種類。

### ⑥ 名前・説明・見どころ
- 名前（シナリオの選択肢に出る）、説明（1〜2 文）、見どころ（1 行ずつ、個体タブのシナリオ欄に出る）。

### 確認と警告（保存の前に表示）
- 群れの個体数が 2 匹未満、または片方の性だけになる群れ。
- 最初の個体数が 2 匹未満。
- 同じ遺伝子座の割合がすべて 0。
- 群れが同じ場所に重なっている（警告だけ。重ねてもよい）。

## 3. データ形式

組み込みシナリオと同じ形に、版と識別子を足す。

```json
{
  "format": 1,
  "id": "my-1727312000",
  "label": "氷の島の二つの家",
  "desc": "…",
  "watch": ["…"],
  "opts": { "islandShape": "single", "geology": "coral", "initialCount": 80 },
  "climateStart": 0.62,
  "freqs": { "MLT": { "W": 0.1 } },
  "traits": { "fur": 0.7 },
  "groups": [
    { "name": "北の家", "share": 1, "place": { "x": 0.5, "y": 0.3, "r": 0.1 }, "clan": true, "origin": 0,
      "freqs": { "COL": { "w": 1 } }, "traits": { "dispM": 0.05, "dispF": 0.05 } }
  ],
  "events": [{ "year": 30, "event": "supercold" }]
}
```

- `traits` を新しく足す：量的形質の「＋」の割合。読み込むときに、その形質の全遺伝子座の `freqs` に展開する。画面で作るシナリオは、量的形質をこちらで持つ。
- 読み込むときは必ず `normalizeScenario()` を通す：知らない項目は捨てる、数値は範囲に収める（割合 0〜1、個体数 2〜1000、年 1〜5000、位置 0〜1、半径 0.02〜0.5）、知らない遺伝子座・対立遺伝子・出来事は捨てる、文字列は長さを切る。人からもらったファイルでも安全に読めるようにするため。

## 4. 保存と共有

- 自作シナリオはブラウザ（IndexedDB）に保存する。島の保存と同じデータベースに、`scenario:<id>` という鍵で入れる。
- シナリオの選択肢は「組み込み」と「自作」に分けて並べる。自作には「直す」「複製」「消す」。
- 共有は **JSON の書き出し・読み込み**：
  - 書き出し：ファイルとして保存、または文字列をコピー。
  - 読み込み：ファイルを選ぶ、または文字列を貼り付け。
- 遊んでいる島の保存データにはシナリオの中身ごと入れる（自作シナリオを消しても、その島は続きから遊べる）。

## 5. 仕組みの変更（エンジン側）

- `World` は今 `opts.scenario`（組み込みの名前）でシナリオを引いている。これを「シナリオの中身そのもの」（`opts.scenarioData`）でも受け取れるようにする。組み込みは名前から中身を引いて同じ道を通す。
- 出来事の予定は `SCENARIOS[this.opts.scenario]` ではなく、World が持つシナリオの中身から読む（保存・復元でも残る）。
- `traits` の展開と `normalizeScenario()` は src/scenarios.js に置き、テストを付ける（範囲外の値・知らない項目・壊れた JSON）。
- 島だけのプレビュー：`generateIsland` を直接呼んで地図に描く（個体は作らない）。

## 6. 作る順番

1. **エンジンと形式**：`scenarioData`、`traits`、`normalizeScenario()`、保存・読み込み（IndexedDB）、JSON の書き出し・読み込み。テスト。
2. **編集画面（地図なし）**：①②④⑤⑥ と、群れの位置を数字で入れる版。これで一通り作れるようになる。
3. **地図で群れを置く**：クリックで中心、ドラッグで半径、円と名前の描画、海の上の警告。
4. **今の島から作る**、確認と警告の表示。

1〜2 で「作って遊べる」、3 で「楽しく作れる」になる。

## 7. 決まったこと・実装の状況

- 編集画面は設定タブの中で切り替える。ただし最初に遊び始める前は、地図の上に「どんな島で始める？」（シナリオのカードと「✏️ 自分でシナリオを作る」）を出して目立たせる。再生・+1 年・続きから・カードを選ぶと消える。
- 遺伝子は形質の単位で指定し、「詳しく」を開いたときだけ遺伝子座ごとに指定する。
- 共有は JSON のファイルと文字列だけ。
- 1〜4 をすべて実装した（src/scenarios.js の normalizeScenario・expandFreqs・scenarioWarnings、src/save.js の listScenarios・saveScenario・deleteScenario、src/ui/scenarioEditor.js、main.js の編集モード・開始画面）。
- 編集中は、遊んでいた島を取っておき、左の地図には下書きで始めた 0 年目の島（個体つき）を出す。「やめる」で元の島に戻る。編集中は自動保存しない。
- 画面の幅が広いときは、群れを置くあいだ地図を画面の上に固定する（編集画面を下へ読み進めても地図に置ける）。

## 8. （当初の）決めてほしいこと

1. **編集画面の場所**：設定タブの中で切り替える（おすすめ。タブが増えない）か、専用のタブを足すか。
2. **遺伝子の指定の細かさ**：形質の単位＋「詳しく」で遺伝子座（おすすめ）か、最初から遺伝子座の単位か。
3. **共有の方法**：JSON のファイル・文字列（おすすめ。確実）だけでよいか、URL に埋め込む方式（長くなる）も欲しいか。
