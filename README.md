# 孤島の遺伝子（isolated-sim）

百匹の架空の有性生物を島に閉じ込めて、自然繁殖させたら遺伝子はどう変わるのか？ を眺めて遊ぶシミュレーションゲームです。
生物は 2 歳で成熟し、**15 歳で必ず死にます**。

ブラウザだけで動きます（依存ライブラリなし）。

## 遊び方

```sh
npm start            # = python3 -m http.server 8000
# → http://localhost:8000 を開く
```

ES モジュールを使っているので、`index.html` を直接ダブルクリックではなく、ローカルサーバー経由で開いてください。

サーバーなしで開ける 1 ファイル版は `npm run build` で `dist/index.html` にできます（CSS と JS をすべて埋め込んだもの）。

- **▶ 再生 / スペースキー**で時間が進みます（1 ステップ = 1 か月）。
- 地図上の個体をクリックすると、**遺伝子どおりに描かれた姿・名前・遺伝子型・保因者かどうか**が見られます。
- 個体には名前があり、家名は**母から子へ**受け継がれます（ミトコンドリアと同じ流れ）。まれにミトコンドリアの突然変異で分家（〇〇流）が生まれます。家の独立・隆盛・断絶は年代記に、いまの家の系統樹は「集団」タブに出ます。
- 「家系図」タブでは、選んだ個体を中心に祖父母〜子を表示し、親族をクリックして創始者までさかのぼったり、今の子孫まで下ったりできます。何度も現れる祖先（近親婚のしるし）は同じ色の枠で示されます。
- ある個体を「📌 固定」してから異性を選ぶと、2 匹の子どもの**表現型の分布を予測**できます（減数分裂を数千回シミュレーション）。
- 気候は地球の氷期と間氷期のように、約 600 年の周期でゆっくり冷えて急に暖まります（周期と振れ幅は設定で変えられます）。
- 「神の介入」で疫病・干ばつ・寒冷期・温暖期・超寒冷期・大嵐・漂着者・捕食者の放流を起こせます。
- 「✏️ 地形を編集」で地図をなぞって陸を盛ったり海を掘ったりでき、沖に小島もつくれます。生き物は泳げませんが、流木でまれに海を渡り、寒冷期に海面が下がると浅瀬が陸橋になります。島ごとの個体数と遺伝的な違い（F_ST）は「集団」タブに出ます。
- 「自然選択」タブで、形質ごとの**実際の生存率と子の数**を見られます。差が毎年安定して出ているかを判定し、中立な「耳の形」を対照群にして判定の確かさを確かめられます。
- 「集団」タブの下には、**子孫が残っている創始者の数**と、今の島の遺伝子が各創始者に何割由来するかが出ます。
- 「集団」「遺伝子頻度」タブで、個体数・遺伝的多様性・近交係数・対立遺伝子頻度の推移、ハーディー・ワインベルグ平衡とのずれが見られます。
- 島の形は「ひとつの島」「離島のある島」（沖の小島は無人から始まる）「群島」（最初の個体が島ごとに散らばる）から選べます。
- 「集団」タブの家の一覧には、家ごとに島全体とはっきり違う遺伝子（「換毛の遺伝子 W が多い」「近親交配が多い」など）が出ます。
- 生き物は**ねぐら（縄張りの中心）**のまわりで暮らし、大人になるとき一度だけ遺伝子で決まる距離を旅立ちます。子は母の近くで生まれるので、同じ家が近くに固まって「集落」ができます（地図の表示「家（母系）」、地図の上の「🏠 縄張り」で家ごとの縄張りを色と境界線で重ねて表示。個体を選ぶと、その個体のねぐらと歩き回る範囲も出ます）。旅立ちの距離はオスとメスで別々に進化し、「オスが出ていく島」にも「メスが出ていく島」にもなります（「集団」タブの「旅立ちの距離」）。
- 百匹は**東と西の二つの土地**から来ていて、その間の雑種は子ができにくいことがあります。海で隔てられた島どうしが別々の道を歩むと、**別の種**に分かれることがあります（年代記と「集団」タブの「種の壁」、地図の表示「東西の由来」で見られます）。
- 「設定」タブで**シナリオ**（島の始まり方）を選べます：四つの村（家ごとに固まって住む）・東と西の出会い（島の両端から始まり、真ん中に交雑帯ができる）・白い島の緑の群れ・氷河期の入口・十匹からの出発・捕食者のいない楽園。始まり方だけを決め、その後の規則は同じです。「✏️ シナリオを作る・直す」で、島の形・地質・群れ（地図をクリックして置き場所、ドラッグで広さ）・遺伝子の割合・予定の出来事を決めた自作シナリオを作れます。自作シナリオはブラウザに保存され、JSON のファイルか文字列で書き出して人に渡せます（「📥 シナリオを読み込む」で読み込み）。最初に開いたときは、地図の上に「どんな島で始める？」が出ます。
- 島は**ブラウザに自動保存**されます（2 分ごと・タブを離れたとき・「💾 保存」ボタン）。次に開いたとき「続きから」を選べます。乱数の状態まで保存するので、再開した島は保存しなかった場合とまったく同じ歴史をたどります。
- 「設定」でシード・初期個体数・島の豊かさ（草の育ちやすさ）・捕食者の数・探索像の強さ・突然変異率・近親交配回避などを変えられます。

## 遺伝のしくみ

4 対の染色体（第 1〜3 染色体 + 性染色体 XX/XY）上に 41 の遺伝子座があり、遺伝子座の位置（cM）にもとづいて減数分裂で交叉（組換え）が起きます。

| 遺伝子 | 遺伝形式 | 対立遺伝子 | 選択 |
|---|---|---|---|
| 体色 | 複対立遺伝子（優劣序列 K > G > w） | 黒 / 緑 / 白 | 足元の地面の色に近いほど捕食されにくい。多数派の色ほど狙われる（探索像） |
| 色素 | エピスタシス（上位遺伝子） | 色あり C / 色なし c | c/c はアルビノ：体色・模様の遺伝子を覆い隠して真っ白になる。目が弱く相手を見つけにくい。K/w C/c どうしの子は 黒 9：白 3：アルビノ 4 |
| 換毛 | 表現型の可塑性（W が優性） | 冬に白くなる W / 一年中同じ b | 12〜2 月だけ白い冬毛。時期は日の長さで決まるので、雪があれば保護色、なければ目立つ |
| 模様 | 共優性（ABO 式血液型型） | 斑点 S / 縞 T / 無地 o | なし |
| 耳の形 | 不完全優性 | 立ち U / 垂れ F | なし（中立 → 遺伝的浮動の観察用） |
| 尾の長さ ×4 座 | 限性遺伝（オスだけに現れる）＋ポリジーン | + / − | メスに好まれるが、捕食者から逃げにくく、多く食べる |
| 尾への好み ×3 座・発光への好み ×2 座 | 限性遺伝（メスだけに現れる）＋ポリジーン | + / − | 好みの強いメスは相手探しに時間がかかる |
| オスの旅立ち ×2 座・メスの旅立ち ×2 座 | 限性遺伝＋ポリジーン | + / − | 大人になるとき一度だけ、生まれた場所から離れる。遠くへ行くと疲れるが、きょうだいとの餌の奪い合いと近親交配を避けられる |
| 体格 ×4 座 | 量的形質（ポリジーン）＋環境のばらつき | + / − | 大きいと寒さに強くモテるが、たくさん食べる |
| 毛皮 ×3 座 | 量的形質（ポリジーン） | + / − | 厚いと寒さに強く暑さに弱い |
| 代謝 ×3 座 | 量的形質（ポリジーン） | + / − | 遅い（燃費がいい）と飢えに強いが、寒さに弱く産む子が少ない |
| 免疫型 | 超優性（ヘテロ接合体優位） | A / B | A/B が病気に最も強い（平衡選択） |
| 発光 | 伴性遺伝（X 連鎖劣性） | N / g | 発光を好むメスに選ばれやすいが、捕食者にも目立つ |
| 警戒声 | 社会行動（血縁選択）。V の数に比例して鳴く | 鳴く V / 鳴かない v | 捕食者に気づくと鳴く。本人は狙われやすく、声の届く範囲の個体は隠れて助かる。親族を助ける規則はないが、縄張りのせいで周りには親族が多い |
| 致死因子 | 劣性致死（体色と 4cM で連鎖） | L / l | l/l は生まれない |
| 有害因子 ×3 座 | 劣性有害（遺伝的荷重） | D / d | d/d は死亡率が上がる → 近交弱勢 |
| 不和合 ×3 組（6 座、うち 2 座は X） | 雑種の不和合（ドブジャンスキー・マラー型） | 祖先型 o / 新型 n | 組の両方の新型を持つと子ができにくい。最初の個体は東か西の土地の出身で、東は組の前半、西は後半に新型を持つ |

近交係数 F は家系図から血縁係数として計算し、表示にだけ使います（近親だから弱る、という規則はありません。弱るのは劣性有害遺伝子がホモになったときだけ）。

## 生態系

- **植生**：草はマスごとに気温に応じて育ち、食べられて減ります。食べ尽くされた地面は土の色になります。同じマスの個体は頭数割りで草を分け合うので、大きい個体ほど足りなくなりやすい。
- **保護色**：目立ちやすさは、体色と足元の地面の色（地図に描かれている色そのもの）の差から計算します。
- **性選択**：大きいオスは他のオスに競り勝ち、そのうえでメスは自分の好みの遺伝子に従って尾や発光を評価します。飾りの見栄えは栄養状態しだいです（正直なシグナル）。好みと飾りが一緒に強まるランナウェイが起きることがあります。
- **捕食者**：個体としては描かず、数だけを持ちます。食べた数に応じて増え、一定の割合で死にます（ロトカ＝ヴォルテラ型の周期が生じます）。よく見かける色を重点的に探す探索像を持つため、多数派の色ほど狙われます（負の頻度依存選択）。

## 観察できる現象

フィッシャーのランナウェイ（尾と好みが一緒に強まる）、捕食者と獲物の個体数の周期、草を食べ尽くした場所で黒が有利になるフィードバック、遺伝的浮動と対立遺伝子の消失・固定、ボトルネック、近親交配と近交弱勢、自然選択（保護色・気候適応）、性選択とのトレードオフ、平衡選択、連鎖による「ヒッチハイク」。

## 開発

```sh
npm test                     # 遺伝エンジンとシミュレーションのテスト（node:test）
node tools/headless.js 300 b # ブラウザなしで 300 年分を実行（シード b）
node tools/metrics.js 20 300 # 20 シード × 300 年で「面白さの指標」を集計（docs/DESIGN.md §8）
npm run build                # 1 ファイル版を dist/index.html に出力（--fragment で外枠なし版）
```

```
index.html, css/style.css
src/
  rng.js        シード付き乱数
  genes.js      染色体・遺伝子座・減数分裂・突然変異・表現型
  pedigree.js   家系と血縁係数・近交係数
  island.js     島の地形生成
  stats.js      対立遺伝子頻度・ヘテロ接合度・HW 期待値
  ecology.js    植生・保護色・捕食者
  world.js      シミュレーション本体（死亡要因・配偶者選択・出来事）
  names.js      個体の名前（シードと ID から決定的に生成）
  ui/           地図・チャート・パネル・個体の姿（creatureArt.js）・家系図（familyTree.js）
  main.js       ゲームループ
test/           単体テスト
tools/headless.js
```
